# 自适应时长 v2：短时截断减少，但长时覆盖尚未通过验收

## 结论与状态

- 首版已提交为 `bd9aee1 feat(prediction): add opt-in adaptive forecast horizons`，未推送。
- 本地开始并完成规则 v2 初步修订：替换原始相邻段最大加速度，默认取消 90°累计转角硬限制。
- 修订未提交、未部署、未修改 worker 运行参数；本轮数据库访问全部只读。
- 同一批历史回放中，有效预测时长不超过 5 秒的记录从 79 条降为 0 条，CV 时长中位数从 5 秒变为 25 秒。
- **这仅表明过度截断减少。CT 和悬停的半径覆盖仍不足，不应据此直接宣称长时预测可信或完成线上验收。**

## 根因与实现

v1 使用原始相邻段速度差的最大值计算加速度，并按 `0.5*a*t²` 在整个未来累积。短间隔与定位噪声会放大这个值，即使使用卡尔曼估计器，稳定性指标仍来自原始位置。v1 的累计转角 90°硬限制也会把 10°/s 转弯的候选限制在 9 秒，5 秒步长下只剩一个点。

v2 使用整个窗口的二次位置趋势检测持续偏离：

1. 每个独立时间只使用一次测量，至少 5 个独立时间。
2. CT 先减去已有模型对应的历史圆弧运动。
3. 将二次时间项对常数和线性项正交化，再求东西、南北加速度。
4. 用现有测量噪声标准差计算二维零趋势噪声门槛。
5. 用超出门槛的幅值参与 `0.5*a*t²` 截断预算。

默认测量标准差仍为 10 米，未根据本批数据搜索参数。噪声门槛使用独立、同方差、各向同性高斯测量假设。该检测是趋势证据启发式，不是加速度置信上界，也不是未来覆盖率承诺。

少于 5 点或时间布局退化时，不宣称有趋势证据，仍保留半径和观测年龄限制。没有趋势证据不代表运动稳定，可能放行更多错误预测，须在独立数据中评估。

累计转角默认值改为 `None`；显式 `--adaptive-max-turn-degrees 90` 仍可恢复旧角度限制。已有服务若继续传此参数，升级代码后限制依然生效。

`horizon_policy.rule_version=2`，新增趋势证据状态、有效点数、拟合加速度和噪声门槛指标。不更换候选运动模型、滤波器、高度算法或数据库结构。

- 快照截止：2026-10-17 15:29:49.798169 +08:00。

- 半径阈值 250 米，观测年龄上限 30 秒。
- v1 使用 `bd9aee1` 中的原策略代码，累计转角上限 90°；v2 默认不设累计转角上限。
- 对照为同样候选轨迹的固定时长版本。
- 按入库到达顺序限制可用观测，不使用当时未到达的数据。
- 与线上轮询及节流不是完全一致的仿真，重复窗口也不是独立样本。

复现命令（先配置 `DATABASE_URL`）：

```bash
uv run python -m scripts.prediction.compare_adaptive_horizons \
  --hours 24 --window-seconds 20 --horizon-seconds 90 \
  --output /tmp/adaptive-comparison.json
```

历史数据可能持续变化；报告含输入摘要 SHA-256，不保证后续查询获得相同快照。脚本会执行指定本地 Git 提交中的旧版代码，不能指定未经审查的提交。

## 误差与覆盖：不能把预测更长当作更准确

三个策略对共同保留的点使用完全相同候选坐标，因此配对误差相同。v2 的保留点更多，单独桶的样本集合不同，不能与 v1 均值直接比较并宣称精度提升。

v2 的部分实际观测匹配结果：

| 模型 / ETA | 样本数 | 平均水平误差 | 半径覆盖率 |
|---|---:|---:|---:|
| CV / 10 秒 | 76 | 32.60 米 | 94.74% |
| CT / 10 秒 | 15 | 63.04 米 | 53.33% |
| CT / 30 秒 | 14 | 90.41 米 | 35.71% |
| CT / 60 秒 | 7 | 121.63 米 | 42.86% |
| hover / 30 秒 | 74 | 43.86 米 | 58.11% |
| hover / 60 秒 | 60 | 110.71 米 | 33.33% |

CV 没有保留到 30 秒的已匹配评估点，不能据此判断该档精度达标。CT 和 hover 仍使用原启发式半径，已明显低估部分真实误差，尤其无法覆盖未来模式切换。后续应校准这两个分支的误差增长和模式变化风险，再决定展示时长及参数。

观测自身不是独立高精度真值。上述样本少、窗口相关，没有独立留出验证或显著性检验。
