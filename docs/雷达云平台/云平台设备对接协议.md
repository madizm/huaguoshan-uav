# 云平台设备对接协议

> 来源：[云平台设备对接协议.pdf](云平台设备对接协议.pdf)。本文整理原文的标题、参数表及示例格式，并保留原文截图。原文中的矛盾或缺失项另行标注，不作为已确认的接口约定。

## 通用约定

| 项目 | 约定 |
| --- | --- |
| 服务地址 | `http://{edge-host}:8003`，实际以部署环境为准 |
| HTTP 请求格式 | `Content-Type: application/json` |
| 查询及指令接口鉴权 | 无（按原文说明） |

## 1. 查询接口（拉取）

### 1.1 盒子全量查询（不分页）

- 方法：`POST`
- 路径：`prodBox/queryAll`（原文未写前导 `/`）
- 鉴权：无

#### 请求示例

```json
{
  "stationId": 3,
  "boxName": "",
  "boxCode": "",
  "counterDevices": [1, 2],
  "accessTimeStart": "",
  "accessTimeEnd": ""
}
```

#### 请求参数

全部可选。

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `stationId` | Long | 站点 ID，精确过滤 |
| `boxName` | String | 盒子名称，模糊匹配 |
| `boxCode` | String | 盒子编码，模糊匹配 |
| `counterDevices` | List<Integer> | 反制类型：`0`=否，`1`=定向，`2`=全向；`[1, 2]`=定向+全向；不传=全部 |
| `accessTimeStart` / `accessTimeEnd` | String | 接入时间起止，格式：`yyyy-MM-dd HH:mm:ss` |

#### 盒子字段说明

| --- | --- | --- |
| `id` | Long | 盒子 ID |

设备经纬度可用于页面渲染，在线状态可用于展示设备状态，盒子编码用于下发指令。

## 2. 指令下发接口（HTTP）

- 方法：`POST`
- 路径：`/api/cloud/command/send`
- 请求格式：`Content-Type: application/json`
- 鉴权：无

所有指令共用以上接口，通过 `cmd` 区分。以下参数表使用 `data.xxx` 表示请求体中 `data` 对象内的字段。

> 原文未提供指令下发接口的响应格式和错误码。

### 2.1 转台控制

#### 请求示例：侦测设备 360° 持续扫描

```json
{
  "stationId": 3,
  "boxCode": "b260410104842483",
  "cmd": "turntable",
  "data": {
    "deviceId": "TCP100",
    "mode": "360"
  }
}
```

#### 参数说明

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `stationId` | Int | 是 | 站点 ID |
| `boxCode` | String | 是 | 盒子编码，从盒子列表中查询得到 |
| `cmd` | String | 是 | 固定为 `turntable` |
| `data.deviceId` | String | 否 | `TCP100` / `TCP99`，默认 `TCP100`；`TCP100` 为 450 侦测设备，`TCP99` 为单面阵打击设备 |
| `data.mode` | String | 是 | `360`=360° 旋转，`angle`=指定角度，`sweep`=钟摆，`stop`=停止旋转 |
| `data.azimuth` | Double | 条件必填 | `mode=angle` 时必填，范围 `0～360°` |
| `data.startAngle` | Double | 条件必填 | `mode=sweep` 时必填，起始角度 |
| `data.endAngle` | Double | 条件必填 | `mode=sweep` 时必填，终止角度 |
| `data.deviceNum` | Int | 否 | `0`=关，`1`=开；默认 `1`，仅 `angle` 有效 |

> 原文部分示例注释将 `TCP100` 写成 `TCO100`，此处按参数表及示例字段值统一为 `TCP100`。

#### 单面阵反制设备 360° 持续扫描

```json
{
  "stationId": 3,
  "boxCode": "b260410104842483",
  "cmd": "turntable",
  "data": {
    "deviceId": "TCP99",
    "mode": "360"
  }
}
```

#### 设备指向指定角度（如 90°）

```json
{
  "stationId": 3,
  "boxCode": "b260410104842483",
  "cmd": "turntable",
  "data": {
    "deviceId": "TCP99",
    "mode": "angle",
    "azimuth": 90
  }
}
```

#### 侦测设备区间钟摆扫描（30° ↔ 150°）

```json
{
  "stationId": 3,
  "boxCode": "b260410104842483",
  "cmd": "turntable",
  "data": {
    "deviceId": "TCP100",
    "mode": "sweep",
    "startAngle": 30,
    "endAngle": 150
  }
}
```

### 2.2 手动开关功放

#### 开启功放（指定频段 2.4G / 5.2G / 5.8G）

```json
{
  "stationId": 3,
  "boxCode": "b260410104842483",
  "cmd": "amp",
  "data": {
    "action": 1,
    "freqs": "2.4,5.2,5.8"
  }
}
```

#### 关闭功放（指定频段 2.4G / 5.2G / 5.8G）

```json
{
  "stationId": 3,
  "boxCode": "b260410104842483",
  "cmd": "amp",
  "data": {
    "action": 0,
    "freqs": "2.4,5.2,5.8"
  }
}
```

#### 参数说明

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `stationId` | Int | 是 | 站点 ID |
| `boxCode` | String | 是 | 盒子编码，从盒子列表中查询得到 |
| `cmd` | String | 是 | 固定为 `amp` |
| `data.action` | Int | 是 | `1`=开启，`0`=关闭 |
| `data.freqs` | String | 否 | 频段列表，逗号分隔，如 `2.4,5.2,5.8`；不传则使用默认频段，原文示例注明默认频段为 2.4G / 5.2G / 5.8G |

> **注意：`amp` 是手动开关。开启后不会自动关闭，需自行发送 `action: 0` 关闭。**

### 2.3 雷达控制

#### 2.3.1 雷达工作开关

请求示例：RP300 雷达开启工作。

```json
{
  "stationId": 3,
  "boxCode": "b260410104842483",
  "cmd": "radarSwitch",
  "data": {
    "radarSn": "RP300",
    "transmitSwitch": 3
  }
}
```

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `stationId` | Int | 是 | 站点 ID |
| `boxCode` | String | 是 | 设备编码（盒子编码） |
| `cmd` | String | 是 | 固定为 `radarSwitch` |
| `data.radarSn` | String | 是 | 目标雷达型号：`RP300` 或 `HX500R` |
| `data.transmitSwitch` | Int | 是 | 发射开关：`0`=全关，`1`=仅收，`2`=仅发，`3`=全开 |
| `data.workMode` | Int | 否 | 工作模式：`0`=凝视（相扫，默认），`4`=机扫；HX500R 使用，RP300 可不传 |
| `data.servoControl` | Int | 否 | HX500R 专用：`0`=自动，`1`=手动，`2`=停止（默认） |
| `data.gazeAngle` | Int | 否 | HX500R 专用，传实际度数，如 `45` 表示 45° |

#### 2.3.2 雷达坐标 / 北向角更新控制

- `cmd`：`radarGpsUpdate`。
- `enabled=1`：开启坐标自动更新。
- `enabled=0`：关闭坐标自动更新，坐标停止刷新，保留最后值。

> **原文示例存在矛盾：**标题为“RP300 北向角更新关闭”，但 `radarSn` 写为 `HX500R`，`enabled` 写为无效 JSON 值 `1 0`。以下保留原示例中的型号 `HX500R`，按参数表选择 `enabled: 0` 演示关闭。这是整理后的示例，不代表已确认原文意图。北向角与坐标更新的具体联动关系，原文未进一步说明。

```json
{
  "stationId": 3,
  "boxCode": "b260410104842483",
  "cmd": "radarGpsUpdate",
  "data": {
    "radarSn": "HX500R",
    "enabled": 0
  }
}
```

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `stationId` | Int | 是 | 站点 ID |
| `boxCode` | String | 是 | 盒子编码 |
| `cmd` | String | 是 | 固定为 `radarGpsUpdate` |
| `data.radarSn` | String | 是 | 目标雷达型号：`RP300` 或 `HX500R` |
| `data.enabled` | Int | 是 | `1`=开启坐标自动更新，`0`=关闭；关闭后保留最后值 |

### 2.4 按目标打击（传飞机 GPS，自动反算方向）

#### 请求示例

```json
{
  "stationId": 3,
  "boxCode": "b260410104842483",
  "cmd": "strike",
  "data": {
    "gps": "120.77045/31.648863",
    "duration": 60,
    "freqs": "2.4,5.2,5.8"
  }
}
```

#### 参数说明

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `stationId` | Int | 是 | 站点 ID |
| `boxCode` | String | 是 | 盒子编码，从盒子列表中查询得到 |
| `cmd` | String | 是 | 固定为 `strike` |
| `data.gps` | String | 是 | 目标无人机 GPS 坐标，格式为 `经度/纬度`，如 `120.77045/31.648863` |
| `data.duration` | Int | 否 | 打击持续秒数，到点自动关闭；不传则读取配置 |
| `data.freqs` | String | 否 | 频段列表，逗号分隔，如 `2.4,5.2,5.8`；不传则使用默认频段，原文示例注明为 `2.4,5.2,5.8` |

## 3. WebSocket 接收

- 订阅地址：`ws://{edge-host}:8003/realTimeAlarmWebSocket`
- 消息结构：`type` 表示事件类型，`payload` 为事件内容。

### 3.1 设备状态事件：`config_status`

每 **2 秒**周期推送一次，用于观察设备在线状态、转台角度、功放状态等。

#### 推送示例

> 原文示例中 `counterAzimuth`、`freqsOn` 后缺少逗号，以下已补齐。

```json
{
  "type": "config_status",
  "payload": {
    "stationId": 3,
    "boxCode": "b260410104842483",
    "online": 1,
    "unattended": 0,
    "controlStatus": 1,
    "controlStatus99": 1,
    "counterVoltage": 220.0,
    "counterCurrent": 5.0,
    "counterPower": 1100.0,
    "temperature99": 45.0,
    "tableAzimuth": 120,
    "tableRotating": 0,
    "tableAzimuth99": 90,
    "counterAzimuth": 300,
    "tableRotating99": 1,
    "freqsOn": "433.0,900.0",
    "radarDeviceSn": "HX500R",
    "radarOnline": 1,
    "radarLng": 120.500000,
    "radarLat": 31.600000,
    "radarAlt": 15.0,
    "radarHeading": 132.5,
    "radarBaseHeading": 130.0,
    "radarGpsUpdateEnabled": 1
  }
}
```

#### `payload` 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `stationId` | Int | 站点 ID |
| `boxCode` | String | 盒子编码 |
| `online` | Int | 盒子在线状态：`1`=在线，`0`=离线 |
| `unattended` | Int | 无人值守模式：`1`=开启，`0`=关闭 |
| `controlStatus` | Int | 侦测设备 TCP100（450 / 350）在线状态：`1`=在线，`0`=离线 |
| `controlStatus99` | Int | 打击设备 TCP99（单面阵）在线状态：`1`=在线，`0`=离线 |
| `counterVoltage` | Double | 打击设备电压（V） |
| `counterCurrent` | Double | 打击设备电流（A） |
| `counterPower` | Double | 打击设备功率（W） |
| `temperature99` | Double | 打击设备温度（℃） |
| `tableAzimuth` | Int | 侦测设备转台当前角度（度） |
| `tableRotating` | Int | 侦测设备旋转状态：`1`=旋转中，`0`=静止 |
| `tableAzimuth99` | Int | 打击设备转台当前角度（度） |
| `counterAzimuth` | 原文未注明 | 打击设备转台角度（度）；原文示例注释建议取此字段 |
| `tableRotating99` | Int | 打击设备旋转状态：`1`=旋转中，`0`=静止 |
| `freqsOn` | String | 当前开启的功放频段，逗号分隔，如 `433.0,900.0` |
| `radarDeviceSn` | 原文未注明 | 雷达设备 SN；原文注释为“如果没有配置雷达则不会推送”，具体指该字段还是雷达相关字段，原文未明确 |
| `radarOnline` | 原文未注明 | 雷达设备在线情况，原文未列出取值定义 |
| `radarLng` | 原文未注明 | 雷达经度 |
| `radarLat` | 原文未注明 | 雷达纬度 |
| `radarAlt` | 原文未注明 | 雷达海拔，原文未注明单位 |
| `radarHeading` | 原文未注明 | 实时朝向 |
| `radarBaseHeading` | 原文未注明 | 雷达零位朝向 |
| `radarGpsUpdateEnabled` | 原文未注明 | 雷达坐标更新状态 |

> `counterAzimuth` 及雷达相关字段的说明由原文示例注释整理而来；原文参数表未列出这些字段的类型。

### 3.2 功放开 / 关事件：`uav_amp_status`

每次开关功放都会推送一条消息。

#### 推送示例

```json
{
  "type": "uav_amp_status",
  "payload": {
    "ampStatus": 1,
    "unattendedType": 0,
    "freq": "2.4,5.2,5.8",
    "serial": "5B4BF5A5...",
    "deviceSn": "b260410104842483",
    "durationSec": null,
    "stationId": 3,
    "time": 1756795200000
  }
}
```

#### `payload` 字段说明

原文仅提供示例注释，未提供字段类型表，以下不额外推定类型。

| 字段 | 说明 |
| --- | --- |
| `ampStatus` | 功放状态：`1`=开，`0`=关 |
| `unattendedType` | 触发来源：`0`=手动，`1`=无人值守自动 |
| `freq` | 本次操作的频段 |
| `serial` | 目标飞机序列号；原文注释表示手动操作时不会有无人机序列号，但未说明此时为缺省、空串还是 `null` |
| `deviceSn` | 打击设备 SN（盒子编码） |
| `durationSec` | 打击持续秒数，手动操作时为 `null` |
| `stationId` | 站点 ID |
| `time` | 事件时间戳，单位为毫秒 |

> 原文 `serial` 注释末尾存在疑似笔误“手动的不会有无人机学历好”。同时，上方原文示例的 `unattendedType` 为 `0`，却包含 `serial` 值；此处保留示例，并提示该字段在手动操作时的实际返回形式需要确认。
